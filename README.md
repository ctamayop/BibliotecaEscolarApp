# BibliotecaEscolarApp

## Descripción del proyecto

BibliotecaEscolarApp es una aplicación de escritorio desarrollada en Java para gestionar una biblioteca escolar.

El sistema permite administrar libros, categorías, estudiantes, usuarios y préstamos, utilizando una interfaz gráfica creada con Java Swing y una base de datos MySQL

Este proyecto corresponde a la Evaluación Final Transversal (EFT) de la asignatura **Desarrollo Orientado a Objetos II**


## Funcionalidades principales

- Inicio de sesión con roles de bibliotecario y estudiante
- Administración de libros y categorías
- Gestión de usuarios y estudiantes
- Registro de préstamos y devoluciones
- Actualización del stock de libros
- Consulta de préstamos activos e historial
- Reportes de préstamos
- Validación de datos ingresados
